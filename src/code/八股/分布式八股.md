# 分布式八股

## 什么是分布式

- 多台独立计算机通过网络连接起来协同工作
  - 优点：
    - 高并发
    - 高性能
    - 高可用
  - 缺点
    - 数据一致性

和 **微服务** 的区别：
- 分布式：偏硬件，是物理部署方式
- 微服务：偏代码，是解耦拆分，将大单体服务拆分成小服务，微服务架构天然就是需要用分布式的方式进行部署的

## CAP 理论

- Consistency：一致性，所有数据备份在同一时间保持一致
- Availability：可用性，有高容灾，一个服务器挂了，不影响系统运行
- Partition tolerance：系统不能在时限内达成数据一致性，必须就当前操作在 C 和 A 之间做出选择

## 分布式 ID

### 什么情况下需要分布式 ID

- 数据库分库分表
- 微服务的多节点环境
- 多系统打通合并数据

### 分布式 ID 有什么方案

- UUID（不推荐）
- 数据库号段模式
